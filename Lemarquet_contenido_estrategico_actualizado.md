# LEMARQUET — Estructura y contenido estratégico del sitio web

## 1. Arquitectura actual de Lemarquet

La comunicación de Lemarquet debe organizarse alrededor de **tres líneas claramente diferenciadas**:

```text
LEMARQUET
│
├── SOLUCIÓN B2B
│   │
│   └── Portal B2B
│       └── Solicitar acceso
│
├── GESTIÓN INTERNA
│   │
│   └── Backoffice
│       └── Operación empresarial
│
└── SERVICIOS A MEDIDA
    │
    ├── Desarrollo
    ├── Integraciones
    ├── APIs
    └── Infraestructura
```

Esta estructura representa la forma más clara de comunicar actualmente el ecosistema de Lemarquet:

- **Solución B2B:** entorno comercial destinado a clientes empresariales.
- **Gestión interna:** entorno administrativo y operativo utilizado para controlar la operación empresarial.
- **Servicios a medida:** capacidades de desarrollo tecnológico para construir, integrar o adaptar soluciones.

> **Principio de comunicación:** el Portal B2B y el Backoffice forman parte del mismo ecosistema tecnológico, pero cumplen funciones diferentes. Los servicios a medida representan una línea independiente de trabajo tecnológico.

# 3. Arquitectura comercial

La página debe evitar presentar todo como un único producto.

La estructura comercial debe distinguir:

| Línea | Qué representa | Usuario principal |
|---|---|---|
| **Solución B2B** | Portal comercial para clientes empresariales | Cliente B2B |
| **Gestión interna** | Backoffice para administrar la operación | Personal interno / operadores |
| **Servicios a medida** | Desarrollo e integración tecnológica | Empresas con necesidades específicas |

Esta separación permite que un visitante entienda inmediatamente **qué puede utilizar, qué puede administrar y qué puede contratar**.

# 6. SOLUCIÓN B2B

## Nombre

**Solución B2B**

## Subtítulo

**Un entorno comercial diseñado para empresas.**

## Descripción

El Portal B2B permite a clientes empresariales acceder a un entorno comercial donde pueden consultar productos, gestionar pedidos y dar seguimiento a sus operaciones de compra.

La solución está orientada a facilitar la relación comercial entre empresas y proveedores dentro de un entorno controlado.

## Funcionalidades principales

### Catálogo

Consulta de productos, información comercial y disponibilidad.

### Productos

Visualización de productos, variantes, atributos y características.

### Pedidos

Creación, consulta y seguimiento de pedidos.

### Carrito y Order Builder

Construcción y preparación de pedidos antes de confirmar la operación.

### Precios comerciales

Aplicación de condiciones comerciales y precios asociados al cliente.

### Cotización y totalización

Consulta de subtotal, impuestos, envío y total antes de completar la operación.

### Pagos

Soporte para métodos de pago disponibles para la operación B2B.

### Crédito

Gestión de operaciones mediante crédito comercial cuando corresponda.

### Historial

Consulta de pedidos y operaciones anteriores.

### Envíos y seguimiento

Consulta de información relacionada con preparación, envío y entrega.

## Acceso

**Sin costo de suscripción.**

El acceso al entorno B2B se realiza mediante **solicitud y autorización**.

# 7. GESTIÓN INTERNA

## Nombre

**Gestión interna**

## Subtítulo

**El centro operativo para administrar el negocio.**

## Descripción

El Backoffice concentra las herramientas necesarias para administrar y supervisar la operación empresarial detrás del entorno comercial.

No es un segundo portal comercial: es el entorno desde el cual se controla la operación.

## Áreas principales

### Usuarios y clientes

Administración de usuarios, clientes empresariales, permisos y acceso.

### Proveedores

Gestión de proveedores y separación de las operaciones correspondientes a cada proveedor.

### Productos y catálogo

Administración de productos, categorías, variantes, atributos y relaciones comerciales.

### Sincronización

Importación, actualización y sincronización de información proveniente de sistemas externos.

### Órdenes

Administración, seguimiento, actualización y control del ciclo operativo de los pedidos.

### Fulfillment

Análisis de disponibilidad y asignación de inventario para determinar cómo puede atenderse cada pedido.

### Integraciones

Conexión con plataformas, proveedores y servicios externos.

### Envíos y calendario

Gestión de envíos, costos, instalaciones y eventos asociados a la operación.

### Facturación

Administración de clientes fiscales, CFDI, folios, facturas y procesos relacionados.

### Métricas y observabilidad

Supervisión de procesos, errores, sincronizaciones, conflictos y estados operativos.

# 8. RELACIÓN ENTRE B2B Y GESTIÓN INTERNA

La comunicación debe explicar que ambas áreas forman parte del mismo ecosistema.

```text
                    LEMARQUET
                        │
          ┌─────────────┴─────────────┐
          │                           │
     PORTAL B2B                  BACKOFFICE
          │                           │
     Cliente B2B                Operación interna
          │                           │
          └─────────────┬─────────────┘
                        │
                 OPERACIÓN COMERCIAL
                        │
        ┌───────────────┼────────────────┐
        │               │                │
    Proveedores      Pedidos          Servicios
        │               │                │
    Catálogos       Fulfillment      Integraciones
        │               │                │
        └───────────────┼────────────────┘
                        │
                  LOGÍSTICA / CFDI
```

## Concepto clave

**El Portal B2B es la cara comercial. El Backoffice es el centro de operación.**

El cliente utiliza el Portal B2B para realizar y consultar sus operaciones.

El equipo interno utiliza el Backoffice para administrar clientes, proveedores, productos, pedidos, inventario, integraciones, envíos y facturación.

# 19. REGLAS DE COMUNICACIÓN

1. Mantener claramente separadas las tres líneas de Lemarquet.
2. No presentar el Portal B2B como si fuera únicamente un catálogo.
3. No presentar el Backoffice como otro ecommerce.
4. Explicar que B2B y gestión interna forman parte del mismo ecosistema.
5. Mantener explícito que el acceso B2B no tiene costo de suscripción.
6. Comunicar que el acceso B2B requiere solicitud y autorización.
7. Presentar los servicios a medida como una línea independiente.
8. Priorizar beneficios empresariales antes que terminología técnica.
9. Evitar listas de tecnologías sin explicar su función.
10. Mantener títulos breves y orientados al usuario.
11. Utilizar CTAs diferentes según la intención del visitante.
12. No utilizar "módulo", "servicio", "plataforma" y "solución" como sinónimos.
13. Evitar promesas comerciales que no puedan demostrarse.
14. Mantener una comunicación profesional, moderna y técnicamente sólida.
15. Mostrar la arquitectura de forma visual y fácil de comprender.

## Concepto central

**Lemarquet no debe comunicarse únicamente como un ecommerce ni únicamente como una empresa de desarrollo.**

La propuesta debe mostrar tres niveles claramente relacionados:

**SOLUCIÓN B2B**  
El entorno donde los clientes empresariales realizan y consultan sus operaciones.

**GESTIÓN INTERNA**  
El entorno donde la empresa administra y controla la operación que sostiene el negocio.

**SERVICIOS A MEDIDA**  
La capacidad de Lemarquet para desarrollar, integrar y evolucionar tecnología según las necesidades particulares de cada empresa.

Esta estructura permite que el sitio explique de forma inmediata **qué es Lemarquet, qué solución ofrece, qué operación puede administrar y qué tecnología puede desarrollar a medida.**
